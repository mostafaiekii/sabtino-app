# 🪪 ثبتینو — اپ خدمات ثبتی، کپی و چاپ

دموی تعاملی و کامل یک اپلیکیشن سفارش‌گیری خدمات (پیشخوان دولت + کافی‌نت و چاپ) با پنل مدیریت، به‌صورت **یک فایل HTML مستقل** — بدون نیاز به نصب، سرور یا بیلد.

## 🚀 اجرا

فایل `index.html` را دانلود و با مرورگر باز کنید (دابل‌کلیک کافی است). روی موبایل هم تمام‌صفحه اجرا می‌شود.

## 🔑 حساب‌های دمو

| نقش | ورود |
|---|---|
| 👤 مشتری (با داده‌های آماده) | نام کاربری `ali` — گذرواژه `123456` |
| 👤 مشتری جدید | هر نام کاربری تازه + شماره موبایل ۱۱ رقمی |
| 👑 مدیر | `admin` / `admin123` |

> برای شروع تمیز: از پروفایل یا صفحه ورود، «↺ ریست داده‌های دمو» را بزنید.

## ✨ امکانات

**سمت مشتری**
- 🧾 سفارش آنلاین خدمات غیرحضوری با پیوست عکس مدارک و فاکتور
- 🕐 نوبت‌دهی حضوری (تقویم ۷ روزه، ساعت‌های رزروشده)
- 🚀 پیگیری لحظه‌ای درخواست با تایم‌لاین و اعلان
- 💳 کیف پول با شارژ کارت‌به‌کارت (شماره کارت مدیر) و درگاه بانکی
- ⭐ امتیاز، استریک روزانه و فروشگاه تبدیل امتیاز
- 🎡 گردونه شانس (چرخش رایگان روزانه + چرخش با امتیاز)
- 🎴 بازی کارت‌ها: گرفتن پک با فعالیت در اپ و شبکه‌های اجتماعی، ست کامل، جایزه نقدی
- 🎨 تم روشن/تاریک + ۴ رنگ‌بندی دلخواه (ذخیره می‌شود)

**پنل مدیریت**
- 📊 داشبورد: درآمد امروز/ماه، سود کل، نمودار ۷ روزه، سهم دسته‌ها
- 👥 درآمد و سودِ رسانده توسط هر مشتری + پرونده کامل هر مشتری
- 🧾 مدیریت وضعیت سفارش‌ها (مشتری همان لحظه مطلع می‌شود)
- 📅 مدیریت نوبت‌ها (ثبت حضور/لغو)
- ✉️ ارسال پیام مستقیم به هر مشتری
- 💳 ثبت شماره کارت دریافت واریز

## 🛠 فناوری

HTML + CSS + JavaScript خالص در یک فایل — داده‌ها در `localStorage` نگهداری می‌شود. فونت وزیرمتن (با جایگزین سیستمی).
